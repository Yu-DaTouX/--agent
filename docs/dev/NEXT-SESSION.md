# 新会话入口

先读 [HANDOFF.md](HANDOFF.md)，再按 [实现总览](../PROJECT.md) 定位功能。文档分工见[文档索引](../README.md)。

可复制以下内容给新会话：

~~~text
阅读 AGENTS.md 和 docs/dev/HANDOFF.md，检查 git status --short，保留已有修改，然后继续用户指定的工作。
按 docs/PROJECT.md 定位实现；按工程 ID 查工程清单的验收条件；架构依赖见实施方案。
测试约定只看 docs/dev/TESTING.md。完成度、剩余任务与证据只更新 HANDOFF，不把历史报告或旧包当成本次通过结果。
~~~
