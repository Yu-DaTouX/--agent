1. **`import` 了 ≠ 渲染了** —— 组件写完要 `git grep '<组件名'` 确认被渲染。
2. **typecheck 绿不等于功能存在**（`noUnusedLocals` 没开，死 import 不报错）。

5. **合成探针会说谎**：探针里把状态机写错就会假绿 —— 要用真模型跑同一条路径复核。
