## 5. 规格（可直接实现）

| 项 | 规格 | 说明 |
|---|---|---|
| 行高 | 26px（保持） | 与左栏会话条目一致，视觉连成一套 |
| 缩进 | 每级 14px，首级 6px | 现在 12px，略紧；14px 更接近参考图 |
| hover | `background: var(--bg-3)` + `border-radius: var(--r-sm)` | 现在是整行铺色无圆角 |
| 键盘焦点 | 同 hover，另加 1px `--accent-line` 内描边 | 焦点与 hover 要能区分（可访问性） |
| 当前项 | `--bg-3` + 左侧 2px `--accent` 竖条 | 复用左栏 `.item.sel::before` 的既有语言 |
| 目录图标 | `folder` / `folder-open`，色 `--fg-mute` | 保持 |
| 文件图标 | 12px 线框（保持），色 `--fg-dim` | 参考图里文件几乎不带色 |
| 体积 | 仍只在 hover 显示 | 你之前的决定，不破坏列表整洁 |
| 「加入上下文」按钮 | 仍 hover/focus 才出现（`opacity` 过渡） | 保持现有行为，不常显 |
| 项目头 | 高度 28px，图标 + 名称 + 右侧计数 + 折叠箭头 | 新增；点击整行折叠/展开根目录 |
| 展开显示 | 超过 **50** 项时在末尾出现，点击后一次展开全部 | 阈值可调；目的是避免长目录把右栏撑爆 |
| 空态/异常态 | 保持现有文案（无权限 / 缺失 / 截断 / 搜索中） | 不新增状态 |
