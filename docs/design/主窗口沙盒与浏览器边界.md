# 主窗口沙盒与浏览器边界（方案第 9 节的实施记录）

> 日期：2026-09-14｜对应方案《Yan-功能升级与UI优化方案-2026-09-14.md》第 9 节。
> 本文记录**实测结论**，不是设计设想 —— 每条都写了验证方式。

## 1. 主窗口沙盒：已迁移，并给出了前提条件

### 结论

主窗口现在是 `sandbox: true`（原为 `false`），`contextIsolation: true`，
`nodeIntegration: false`。

### 迁移过程（一次失败，不是猜出来的）

1. 先只改 `sandbox: true`（preload 仍是 electron-vite 默认的 `.mjs`）→
   **界面完全空白**：`window.yan` 是 `undefined`，探针报
   `Cannot read properties of undefined (reading 'describeFiles')`，
   `live` 探针量到三栏宽度 0、图标引用 0。
   原因：**sandboxed preload 不支持 ESM**。
2. 把 preload 构建改成 **CJS**（`output.format = 'cjs'`，
   `entryFileNames = '[name].cjs'`，主进程加载 `../preload/index.cjs`）。
3. 重跑探针：`live / terminal / reasoning / trash / linkpreview / fs /
   atPath / dialog / light` 全部通过，界面完整（图标引用 55 个、无空引用）。

### preload 的能力清单（这就是迁移的边界）

`src/preload/index.ts` 只用了三个 Electron 模块：

| 模块 | 用途 | sandbox 下可用 |
| --- | --- | --- |
| `contextBridge` | 暴露白名单 API | ✅ |
| `ipcRenderer` | 所有 IPC invoke | ✅ |
| `webUtils` | `getPathForFile`（把拖入的 File 换成路径） | ✅ |

没有任何 `node:fs` / `node:path` / `require` 依赖，所以**不需要**为迁移
再补 IPC。

### 注意

- `electron-builder.yml` 若显式列出了 preload 文件名，需要一起改成 `index.cjs`；
- 打包后必须再验一次（本文只覆盖开发构建与 `out/` 运行路径）。

## 2. 浏览器权限：默认拒绝 + 可查看

- 远程网页的 `session`（`persist:yan-browser`，本来就开了
  `sandbox: true` / `contextIsolation` / 关闭 `nodeIntegration`）
  现在装了：
  - `setPermissionRequestHandler` → **一律拒绝**，并把 `权限 + 来源`
    记进 `BrowserState.permissions`（最多 40 条）；
  - `setPermissionCheckHandler` → 一律拒绝。
- 为什么不按关键词判断“这个站点可不可信”：摄像头/麦克风/定位/通知/
  剪贴板在 agent 场景没有正当用途，而关键词判断既不可靠也容易被绕过。
- 界面上：浏览器「⋯」菜单里显示「已拒绝 N 个权限请求」，悬停可看明细
  （`data-testid="browser-permissions"`）。

## 3. 本地预览边界（有明确局限）

规则：目标是回环/私有地址（`localhost`、`*.localhost`、`127.*`、`10.*`、
`192.168.*`、`172.16–31.*`、`0.0.0.0`、`[::1]`）时，
**只允许由本地页面发起**；远程页面发起的这类请求被取消。

已知局限（写在代码注释里，不假装完备）：

- 拿不到顶层页面 URL 的请求**放行** —— 宁可少拦，也不误杀正常的
  图片/字体请求；
- 拦截发生在 `webRequest.onBeforeRequest`，DNS 重绑定这类攻击需要在
  网络栈更底层处理，不在本次范围；
- pi 侧的 loopback bridge 已有独立防线：只监听 `127.0.0.1`，
  并要求随机 `x-yan-browser-token`（token 只在 pi 的环境变量里）。

## 4. 下载

`will-download` → 落到系统下载目录，`BrowserState.lastDownload` 现在带
**来源 URL**，界面显示「已下载 xxx（未自动打开）· host」。
下载完成后**不会**自动执行文件。

## 5. 仍然**没有**的东西（别误读）

- 主窗口有了进程沙盒，**不代表 pi 执行的命令被沙盒了**。pi 仍然以当前
  用户身份读写文件、跑命令。命令层的文件系统/网络限制是独立功能，
  本次没做，也不应该对用户宣传成“本地命令完全安全”。
- 浏览器分区（`persist:yan-browser`）只是数据隔离，不是无痕模式，
  也不是项目级隔离。

## 6. 验证方式

```bash
npm run typecheck
npm run build
npm run test:live -- live terminal trash linkpreview fs atPath dialog light
```

探针在 `sandbox: true` 下运行并全部通过；`live` 的图标引用数与三栏宽度
是「界面真的渲染了」的直接证据（空 preload 时它们会是 0）。
